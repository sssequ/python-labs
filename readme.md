# мессенджер

лабораторная работа по прикладному программированию. консольный мессенджер,
в котором можно создавать пользователей и чаты, отправлять и читать сообщения.

## запуск

нужен python 3.10 или новее. в pycharm запустить `main.py` или из папки проекта:

```bash
python3 main.py
```

в меню нужно выбрать действие и ввести запрошенные данные. пользователи, чаты
и сообщения выбираются по id, который программа выдаёт при создании.
данные хранятся в памяти и после закрытия программы не сохраняются.

## структура проекта

| файл | назначение |
| --- | --- |
| `main.py` | запуск программы, меню, ввод и вывод |
| `data_layer.py` | классы пользователей, сообщений и чатов |
| `repository_layer.py` | хранение, поиск, изменение и удаление объектов |
| `service_layer.py` | работа с пользователями, чатами и сообщениями |

## пример работы

1. выбрать пункт 1 и создать пользователей `alex` и `bob` — их id будут 1 и 2.
2. выбрать пункт 3 и создать чат от пользователя 1 — id чата будет 1.
3. через пункт 5 добавить пользователя 2 в чат 1.
4. через пункт 6 отправить сообщение в чат 1 от пользователя 1.
5. через пункт 7 посмотреть сообщения чата 1 от пользователя 2.

## правила и ошибки

- имя пользователя должно быть уникальным и состоять из английских букв;
- `alex` и `Alex` считаются одинаковыми именами;
- название чата и сообщение не могут быть пустыми или состоять из пробелов;
- в сообщениях можно использовать цифры, знаки и эмодзи;
- отправлять и читать сообщения могут только участники чата;
- изменять и удалять сообщение может только его отправитель;
- повторно добавить одного участника в тот же чат нельзя.

если введены неверные данные или действие запрещено, программа показывает
сообщение об ошибке и возвращается к меню.
